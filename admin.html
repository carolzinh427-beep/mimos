Integração com Supabase

Conecte seu projeto Supabase para armazenar a tabela de produtos e usar o Supabase Storage para uploads de imagens.

Script SQL para criar a tabela no Supabase:
CREATE TABLE IF NOT EXISTS produtos (
  id TEXT PRIMARY KEY,
  name TEXT NOT NULL,
  category TEXT NOT NULL,
  detail TEXT,
  price NUMERIC,
  image TEXT,
  tag TEXT,
  created_at TIMESTAMPTZ DEFAULT NOW()
);

-- Habilita Row Level Security
ALTER TABLE produtos ENABLE ROW LEVEL SECURITY;

-- Permite que todos os clientes vejam o catálogo
CREATE POLICY "Leitura pública" ON produtos FOR SELECT USING (true);

-- Permite gravação pelo painel administrativo
CREATE POLICY "Gerenciamento completo admin" ON produtos FOR ALL USING (true) WITH CHECK (true);
